# Space Health - Portal Virtual

Este es el portal virtual de Space Health, una plataforma moderna para servicios médicos en línea.

## Características

- Consultas virtuales
- Revisión de exámenes
- Programación de citas
- Coordinación de cirugías

## Tecnologías Utilizadas

- React
- TypeScript
- Tailwind CSS
- Vite
- Lucide React

## Requisitos

- Node.js 18 o superior
- npm 9 o superior

## Instalación

1. Clona el repositorio:
```bash
git clone [URL_DEL_REPOSITORIO]
```

2. Instala las dependencias:
```bash
npm install
```

3. Inicia el servidor de desarrollo:
```bash
npm run dev
```

## Estructura del Proyecto

```
space-health/
├── src/
│   ├── components/     # Componentes reutilizables
│   ├── App.tsx        # Componente principal
│   └── main.tsx       # Punto de entrada
├── public/            # Archivos estáticos
└── package.json       # Dependencias y scripts
```

## Actualizaciones

Para mantener el proyecto actualizado:

1. Si usas Git:
   - Haz pull de los cambios: `git pull origin main`
   - Instala nuevas dependencias: `npm install`

2. Si no usas Git:
   - Guarda una copia de tu `.env` y archivos de configuración local
   - Descarga la nueva versión
   - Copia tus archivos de configuración
   - Ejecuta `npm install`
